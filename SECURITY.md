# Security Policy

## 취약점 신고 / Reporting a Vulnerability

보안 취약점은 공개 이슈가 아니라 **비공개로** 신고해 주세요.
Please report security vulnerabilities privately, never via public issues.

- GitHub: **Security → Advisories → Report a vulnerability** (private vulnerability reporting)
- Email: jungho@korpay.com

72시간 내 확인 목표 / We aim to acknowledge within 72 hours.

## 지원 범위 / Supported

기본 브랜치(`public/main` · `private/main`)의 최신 릴리스 / Latest release on the default branch.
